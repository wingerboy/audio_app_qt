# 音频转录与分段工具

这是一款专为Windows平台设计的本地桌面应用程序，旨在帮助用户高效地将本地音频或视频文件中的语音内容转录为文字，并提供基于文本内容的智能分割、关键词筛选和片段精确切割导出功能。

## 功能特点

- **音频提取**：从视频文件中提取音频内容
- **语音转录**：使用Whisper模型将音频转录为文字
- **智能分段**：基于语义和时间长度进行智能分段
- **关键词过滤**：支持通过关键词过滤不需要的内容片段
- **片段导出**：支持将分段结果导出为多种音频格式

## 安装要求

1. Python 3.7 或更高版本
2. FFmpeg（用于处理视频文件和某些音频操作）
3. 必要的Python库（见requirements.txt）

## 安装步骤

1. 安装Python 3.7+
2. 安装FFmpeg并确保可以从命令行访问
3. 安装依赖库：

```bash
pip install -r requirements.txt
```

## 使用方法

1. 运行应用程序：

```bash
python main.py
```

2. 在界面中选择一个音频或视频文件
3. 设置转录参数（模型、语言、分块大小）
4. 点击"开始转录"按钮
5. 转录完成后，设置分段参数和可选的关键词过滤
6. 点击"开始分段"按钮
7. 分段完成后，设置导出参数
8. 点击"导出分段"按钮，选择保存位置

## 注意事项

- 第一次运行时，程序需要下载指定的Whisper模型，请确保网络连接正常
- 对于较大的音频/视频文件，处理可能需要较长时间
- 使用GPU可以显著加快转录速度

## 常见问题

**Q: 为什么转录速度很慢？**  
A: 转录速度受多种因素影响，包括：使用的模型大小、设备配置（GPU/CPU）、音频长度等。使用较小的模型（如tiny或base）或启用GPU可以加快速度。

**Q: 支持哪些语言？**  
A: 支持常见语言如中文、英文、日文、韩文等。Whisper模型本身支持多种语言，选择正确的语言可以提高转录准确性。

**Q: 导出的音频质量如何？**  
A: 音频质量可通过输出格式和比特率控制，支持MP3、WAV、OGG、FLAC等格式，比特率从96k到320k。
